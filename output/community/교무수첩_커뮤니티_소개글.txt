[공유·업데이트] AI로 만들고, 미리 보며 배치하는 나만의 Notion 교무수첩

- 학생 명단, 상담, 시간표, 진도표, 업무와 학사일정을 내 Notion에서 관리할 수 있도록 교무수첩 제작용 GitHub 저장소를 공개합니다.
- 학교·담당 수업·필요한 기능을 웹에서 선택하면, 사용하는 AI에게 전달할 설치 요청문을 만들 수 있습니다.
- 이번에는 수첩 전체 배치 미리보기와 드래그앤드롭 편집, 열 나누기, 기존 수첩 수정 요청문 만들기를 추가했습니다.

■ 이번에 달라진 점
- 만들기 전에 전체 배치 확인: 홈 / 학급 경영·학생 상담 / 교과 진도표·시간표 / 학사 캘린더·PARA, 네 화면을 미리 볼 수 있습니다.
- 드래그앤드롭: 구역의 순서를 바꾸거나 옆으로 옮겨 열을 만들 수 있습니다. 놓일 위치와 열 구성이 반투명으로 표시됩니다.
- 열 편집: 한 행을 1~4열로 나누거나 합치고, 다른 구역을 새 열로 가져올 수 있습니다. 열 너비는 퍼센트로 조절하거나 균등하게 맞추며, 되돌리기도 지원합니다.
- 확인한 배치로 적용 요청: 배치 파일과 AI 요청문을 함께 전달해 같은 구조로 만들도록 요청합니다. 미리보기는 HTML로 저장해 보관·공유할 수도 있습니다.
- 기존 수첩 수정: 웹에서 바꾸고 싶은 기능을 고르면 수정 요청문을 만듭니다. 기존 학생·상담·수업 기록을 유지하면서 필요한 부분을 바꾸도록 안내합니다.
- 공통 배치와 설치 확인 강화: 기본은 전체 너비 페이지입니다. 행·열·폭·접기 구조와 원본 연결을 정하고, 적용 후 실제 Notion 화면까지 확인하도록 설치 절차를 보완했습니다.

■ 교무수첩에 들어 있는 기능
- 학년도마다 한 권: 3월부터 다음 해 2월까지 사용하며, 2학기도 같은 수첩을 이어 씁니다.
- 학생 명단·상담 이력: 상담에 학생을 연결하면 해당 학생의 누적 상담 기록을 확인합니다.
- 업무·일정: P1~P4 우선순위와 업무 종류, PARA의 프로젝트·상시 업무·자료·보관 분류를 활용합니다.
- 주간·월간 캘린더: 하나의 데이터베이스에서 보기만 전환합니다. 연속된 날짜의 같은 학사행사는 기간 일정 하나로 묶습니다.
- 시간표·진도표: 홈과 교과 화면에서 같은 주간 수업표를 보고, 교과·반별 진도를 관리합니다. 수업은 업무·To-Do에 섞지 않습니다.
- 오늘의 중식·학사일정: NEIS 공개 자료를 활용합니다. 클라우드 연결과 Notion 승인을 마치면 컴퓨터를 꺼도 하루 한 번 갱신할 수 있습니다. 공용 연결은 시범 운영 중이며 이용 한도에 따라 처리가 지연될 수 있습니다.
- 선택 기능: 출결·제출물, 평가·채점, 학부모 연락 후속 조치, 회의록, 교직원 연락망, 학교 계정 관리.
- 기록 양식 6종: 학생 상담 / 학부모 연락·상담 / 회의록·후속 조치 / 수업 계획·성찰 / 평가 계획·채점 / 조회·종례 전달사항.

■ 처음 사용하는 순서
1. 웹 질문지에서 학교·학년도·담당 수업과 필요한 기능을 선택합니다.
2. 필요하면 전체 배치 미리보기에서 구역과 열을 조정합니다.
3. 설치 요청문을 AI에게 전달합니다. 배치를 편집했다면 네 화면을 확인한 뒤 저장한 reviewed-layout.json과 배치 적용 요청문도 함께 전달합니다.
4. AI가 만든 실제 Notion 수첩을 확인하고, 이후에는 수정 요청문이나 대화로 필요한 부분을 고칩니다.

■ 사용 전에 확인해 주세요
- 웹은 설정·미리보기·요청문을 만드는 도구입니다. 실제 Notion 생성·수정에는 Notion 쓰기 도구가 연결된 AI 또는 실행 환경이 필요합니다. GitHub 주소만 전달해 시작할 때도 같은 공통 질문지를 따르도록 구성했습니다.
- 미리보기는 구역과 열의 구조를 확인하는 용도이며, 글꼴·줄바꿈·표 높이까지 Notion과 완전히 같지는 않습니다. 웹에서 배치를 바꾸는 즉시 Notion이 바뀌지는 않습니다.
- 컴시간 연동은 선택 기능입니다. 학교 코드·교사 번호와 담당 수업을 확인하며, 서비스 변경의 영향을 받을 수 있습니다. 중식·학사일정의 하루 한 번 클라우드 갱신에는 컴시간이 포함되지 않습니다.
- 기존 수첩에 새 버전이 일괄 적용되지는 않습니다. 지원하는 업데이트를 선택하거나 AI에게 필요한 변경을 요청하는 방식입니다.
- 학생 상담 내용·연락처·API 키·비밀번호는 웹 질문지나 공개 저장소에 입력하지 않습니다. 코드와 문서는 MIT 라이선스로 공개하며, AI 서비스와 클라우드 연결의 비용·이용 한도는 별도입니다.
