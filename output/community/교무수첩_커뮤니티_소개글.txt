[공유] AI와 함께 만드는 나만의 Notion 교무수첩

- 학생 명단, 상담, 시간표, 진도표, 업무와 학사일정을 한곳에서 관리하는 교무수첩 제작용 GitHub 저장소를 공유합니다.
- 학교·담당 수업·필요한 기능을 정하고, AI에게 내 Notion에 맞춰 만들어 달라고 요청할 수 있습니다.

■ 어떤 기능이 있나요?
- 학년도마다 수첩 한 권: 3월부터 다음 해 2월까지 사용합니다. 2학기도 같은 수첩을 이어 쓰고, 진도표에서만 필요에 따라 학기를 구분합니다.
- 네 가지 화면: 홈 / 학급 경영·학생 상담 / 교과 진도표·시간표 / 학사 캘린더·PARA.
- 학생별 상담 이력: 상담 기록에 학생을 지정하면 해당 학생의 누적 이력을 확인할 수 있습니다.
- 업무 관리: P1~P4 우선순위와 업무 종류로 할 일을 정리하고, PARA 방식으로 프로젝트·상시 업무·자료·보관 항목을 관리합니다.
- 주간·월간 캘린더: 같은 데이터베이스에서 보기만 바꿉니다. 연속된 날짜의 같은 학사행사는 하나의 기간 일정으로 묶습니다.
- 주간 시간표: 홈과 교과 화면에서 교시×요일 표로 봅니다. 업무·To-Do와 별도로 관리하며, 파일 가져오기와 선택형 컴시간 웹 연동을 지원합니다.
- 오늘의 중식·학사일정: NEIS 공개 자료를 활용합니다. 별도 클라우드 연결·Notion 승인 후 컴퓨터를 꺼도 하루 한 번 갱신할 수 있습니다.
- 선택 기능: 출결·제출물, 평가·채점 현황, 학부모 연락 후속 조치, 회의록, 교직원 연락망, 학교 계정 관리.
- 자주 쓰는 양식 6종: 학생 상담 / 학부모 연락·상담 / 회의록·후속 조치 / 수업 계획·성찰 / 평가 계획·채점 / 조회·종례 전달사항.

■ 어떻게 시작하나요?
- 아래 웹 질문지에서 학교·학년도·담당 수업·필요한 기능을 선택합니다.
- 설치 요청문을 복사해 Notion 쓰기 도구가 연결된 AI에 전달합니다. 로컬 실행이 가능한 경우 Python 설치도 지원합니다.
- 웹 질문지는 요청문을 만듭니다. 실제 Notion 생성은 연결된 AI와 실행 도구가 담당합니다.
- 만든 뒤에도 “홈 배치를 바꿔 줘”처럼 AI에게 수정을 요청할 수 있습니다. 새 버전은 지원하는 변경을 선택 적용하며 기존 기록을 일괄 덮어쓰지 않습니다.

■ 사용 전에 알아둘 점
- 컴시간은 비공식 연동이며 학교 코드·교사 번호와 담당 수업을 확인합니다. 학교나 서비스 변경에 영향을 받을 수 있고, 매일 클라우드 갱신 대상에서는 제외됩니다.
- 기능과 양식은 필요한 것만 선택합니다. 학생 명단·상담 내용·API 키·비밀번호는 웹 질문지나 공개 저장소에 올리지 않습니다.
- 코드와 문서는 MIT 라이선스로 공개합니다. 이용하는 AI 서비스와 서버 운영의 요금·한도는 별도입니다.
