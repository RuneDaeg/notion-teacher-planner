# 복사해서 쓰는 기록 양식

`양식 모음`은 제목·작성 항목·빈 기록 영역을 갖춘 재사용 페이지 모음이다. 상담 기록, 학부모 연락, 회의록, 수업 기록, 평가 계획, 조회·종례 기록의 여섯 양식을 제공한다. 학생·연락처·실제 상담 내용이나 예시 성적을 미리 넣지 않는다.

양식은 **복사용 페이지 형식**이다. Notion DB의 `새로 만들기` 메뉴에 네이티브 템플릿으로 자동 등록하거나 클릭만으로 새 기록을 만드는 기능은 아니다. 네 핵심 업무 페이지와 기존 DB·뷰 수는 유지하며 별도 양식 모음 페이지와 선택한 양식 페이지를 둔다.

## 선택

**새 수첩을 설치하기 전** `.local/config.json`의 최상위 `forms`에 필요한 키를 적는다. 기존 수첩의 추가 설치에서는 원래 config를 그대로 사용한다.

```json
{
  "forms": ["counseling", "guardian", "meeting", "lesson", "assessment", "homeroom"]
}
```

| 키 | 양식 · 미리 읽기 | 기록할 DB · 조건 |
| --- | --- | --- |
| counseling | [학생 상담 기록](../templates/forms/counseling.md) | 상담 기록 |
| guardian | [학부모 연락 기록](../templates/forms/guardian.md) | 학부모 연락 · `modules.contact` |
| meeting | [회의록 · 결정 · 후속 조치](../templates/forms/meeting.md) | 회의록·결정 사항 · `modules.meeting` |
| lesson | [수업 계획 · 성찰](../templates/forms/lesson.md) | 수업 진도 |
| assessment | [평가 계획 · 채점 기록](../templates/forms/assessment.md) | 평가·채점 현황 · `modules.assessment` |
| homeroom | [조회 · 종례 기록](../templates/forms/homeroom.md) | 수업·업무 자료 · 담당 반 중 `homeroom=true`가 있음 |

`forms`를 생략하면 현재 모듈·담임 설정에서 사용할 수 있는 양식을 선택한다. `[]`는 양식을 선택하지 않는 설정이며 양식 모음 페이지도 만들지 않는다. 명시적으로 적었어도 해당 모듈·담임 조건이 맞지 않는 양식은 제외한다. 양식을 추가하려고 교사가 선택하지 않은 DB 모듈을 임의로 켜지 않는다. 기존 설치 후 `forms`나 모듈을 수정하면 config 불일치로 중단한다. 양식 선택을 바꾸기 위해 상태를 초기화하거나 기존 config에 항목을 덧붙이지 않는다. 새 설정은 별도 새 수첩에 사용하거나 대상과 기록을 확인한 별도 변경 작업으로 다룬다.

## 만드는 방법

새 수첩 설치는 기본 급식 안내 영역과 선택한 양식 모음을 함께 만든다. `plan` 또는 `setup-extras` 미리보기에서 실제 선택된 양식 제목을 확인한다. 기존 Python 설치에는 다음 명령으로 추가할 구성을 먼저 확인한다.

```bash
python -m teacher_planner setup-extras --config .local/config.json --state .local/state.json
python -m teacher_planner setup-extras --config .local/config.json --state .local/state.json --apply
```

`--apply`는 기존 완료 상태와 같은 config, 설치 당시 Notion 연결을 사용한다. 기존 홈·업무 페이지·DB·보기·수동 기록을 재생성하지 않는다. 추가 영역의 ID를 로컬 상태에 기록하므로 상태 파일을 보존한다. 이 명령은 NEIS 식단을 자동 조회하지 않는다.

## 기록할 때

1. 홈에서 `양식 모음`을 열고 필요한 양식의 작성 항목을 확인한다.
2. 양식 페이지를 복제해 안내의 기록 DB로 이동하거나, 해당 DB에 새 행을 만든 뒤 `작성 양식` 본문을 복사한다. 원본은 빈 상태로 유지한다.
3. 날짜·학생·학급·관계·학년도 등의 DB 속성은 별도로 입력한다. 조회·종례는 수업·업무 자료 DB에 두고 이름·학년도·쓰임을 입력하며 실제 날짜와 학급은 본문에 적는다.
4. 상담·연락에서 후속 업무가 생기면 필요한 업무만 업무·일정에 등록하고 관계를 연결한다. 양식 복사만으로 일정이 생성되거나 내용이 다른 DB로 이동하지 않는다.

반복 사용을 원하면 대상 DB의 새 템플릿에 `작성 양식` 본문을 직접 복사해 등록할 수 있다. 이는 사용자가 추가로 설정하는 단계다. 특정 학생·반·날짜를 기본값으로 고정하지 않는다.

수업 기록 양식은 수업 진행과 다음 수업을 적는 형식이며 시간표 수업을 업무·일정·To-Do에 복사하지 않는다. 평가 계획의 채점 현황은 실제 평가 DB 속성에 기록한다. 학부모 연락 양식을 작성해도 메시지를 자동 발송하지 않는다.

교사가 양식 본문을 수정해 사용한 경우 재실행으로 내용을 덮어쓰지 않는다. 설치된 양식을 바꾸거나 정리할 때는 실제 페이지와 기록을 확인한 별도 작업으로 진행한다. 생성 결과가 불확실하면 [RECOVERY.md](RECOVERY.md)를 따른다.
