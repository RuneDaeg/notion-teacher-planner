# 하루 3분, 주간 10분

## 아침

대시보드에서 주간 시간표·오늘 상담·출결과 주간 캘린더를 확인하고 우선순위 To-Do에서 P1, P2를 고른다. 홈과 교과 진도표 & 시간표 페이지의 주간 격자에서 월~금과 교시를 교차해 수업을 확인한다. 두 페이지는 같은 원본의 같은 주간을 표시한다. 오늘 수업만 확인하려면 관리용 오늘 수업 목록을 연다. 수업 데이터 확인·수정은 격자 아래 `시간표 원본 · 관리용` 영역에서 진행한다. 접기 영역으로 배치했다면 펼쳐서 확인한다. 파일·컴시간 반영 후 원본 수업과 두 페이지의 격자가 갱신되며 수업은 업무·일정이나 To-Do에 자동 추가되지 않는다. 격자 직접 편집은 원본 DB를 바꾸지 않는다. 공유 표의 수동 변경은 다른 페이지에도 보일 수 있다. 새 업무는 수집함에 한 줄로 적는다. 할 일의 실행 날짜와 제출 마감이 다르면 둘 다 입력한다.

## 수업과 학생 기록

교과 페이지에서 수업 후 해당 반·단원의 완료 차시와 다음 수업을 기록한다. 학급 페이지에서 학생 관찰 태그와 집중 관찰을 관리하고 조회·종례 메모에는 날짜를 함께 적는다. 학생 상담은 관찰 사실과 합의 사항을 구분해 적고 후속 업무를 연결한다. 출결·제출물은 반별로 확인한다. 직접 새 행을 만들 때 학년도를 넣는다.

상담을 기록할 때는 `학생` 관계에서 실제 학생을 선택한다. 학생 페이지의 `상담 기록` 관계에 같은 원본이 자동으로 연결된다. 공통 상담 이력 레이아웃을 구성한 수첩에서는 학생 페이지의 목록으로 과거 기록까지 확인하고, Python 관계만 설치한 수첩에서는 관계 속성을 열어 확인한다. 이력에는 오늘·현재 학년도 제한을 두지 않으므로 같은 학생 페이지에 연결된 예전 상담도 남는다. 이름을 제목이나 본문에만 쓴 기록은 연결되지 않는다. 이력이 빠졌다면 복사본을 만들기 전에 원본 상담의 학생 관계를 확인한다.

## 금요일

학사 캘린더 & PARA 페이지에서 다음 주 일정과 마감을 확인한다. 수집함에서 분류·우선순위·다음 행동을 정한다. P2 업무의 다음 주 시간을 확보한다. 끝난 프로젝트와 더 이상 쓰지 않는 자료에 보관을 체크한다. 보관은 삭제가 아니며 관계는 유지된다.

## 학기와 학년도가 바뀔 때

수첩은 학년도마다 한 권을 해당 연도 3월부터 다음 해 2월까지 사용한다. 2학기에도 같은 수첩에서 학생·상담·업무 기록을 이어 간다. 필요한 수업 진도 기록에 `학기`를 선택해 1·2학기 보기로 구분하며, 기존 기록을 초기화하거나 복제하지 않는다.

제목에 `1학기`가 남아 있어도 계속 사용할 수 있다. 제목만 바꾸고 싶으면 AI에게 기존 페이지 제목 변경을 요청한다. 제목 변경은 DB 구조 변경이 아니며 원래 설정과 설치 상태는 유지한다. 다음 학년도에는 이전 수첩과 기록을 보존하고 새 학년도 수첩을 준비한다. 양식의 학년도 기본값, 캘린더 필터, 학교 연동 대상 학년도는 새 수첩에 맞게 확인한다.

## 새 기능을 적용할 때

홈의 **업데이트 확인**에서 변경 설명을 읽고 원하는 항목만 적용한다. 기존 수첩에 링크가 없으면 AI에게 한 번 추가해 달라고 요청한다. 첫 항목인 학생별 상담 이력 연결은 기존 양방향 관계를 확인하거나 빈 상담 DB의 관계를 구성하며, 상담 기록이 있는 단방향 관계는 AI가 기록을 보존하며 확인하도록 남긴다.

**관계 연결 확인 · 화면 설정 대기**라면 학생 페이지에서 지난 상담과 상담일 내림차순 정렬을 실제로 확인한 뒤 **화면 확인 완료 기록**을 누른다. 이 버튼은 교사의 화면 확인을 기록한다. 서버가 레이아웃까지 자동 검증하는 것은 아니다. 로그인 시간이 지났으면 홈 링크에서 다시 연결한다. 자세한 순서와 AI 요청문은 [기존 수첩 업데이트](UPDATES.md)를 따른다. Git·서버가 바뀌어도 선택하지 않은 수첩 화면을 일괄 변경하지 않는다.

## AI에게 맡기는 예

```text
이번 주 미완료 업무를 보고 우선순위 조정안을 제안해줘.
마감과 중요도를 나눠 설명하고, 내가 선택한 변경을 반영해줘.

1학년 1반 영어 2단원 진도를 보여줘.
오늘 한 차시를 진행했으니 완료 차시를 1 늘리고 다음 수업을 본문 독해로 적어줘.

이 회의록의 결정 사항을 후속 업무로 만들어줘.
담당이나 마감이 명시되지 않은 것은 추정하지 말고 비워 두거나 물어봐줘.

이 상담 기록에 다음 주 화요일 후속 확인 일정을 연결해줘.
캘린더 제목에는 학생 이름이나 상담 내용을 넣지 마.

이 시간표 파일을 검사한 뒤 내 Notion 시간표에 반영해줘.
변경 수업은 교사 시간표에 갱신하고 휴강을 표시해줘.
홈과 교과 페이지의 주간표에서 같은 주와 수업이 보이는지 확인하고, 업무·일정에는 복사하지 마.
```

AI가 학생 기록을 읽는 요청은 필요한 학생과 날짜로 범위를 좁힌다. 기록의 사실관계를 임의로 보완하거나 보호자에게 자동 발송하지 않는다. 일정 등록 자체가 알림이나 반복 실행을 설정하는 것은 아니다.
