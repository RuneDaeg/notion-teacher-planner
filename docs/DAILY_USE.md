# 하루 3분, 주간 10분

## 아침

대시보드에서 주간 시간표·오늘 상담·출결과 주간 캘린더를 확인하고 우선순위 To-Do에서 P1, P2를 고른다. 홈과 교과 진도표 & 시간표 페이지의 주간 격자에서 월~금과 교시를 교차해 수업을 확인한다. 두 페이지는 같은 원본의 같은 주간을 표시한다. 오늘 수업만 확인하려면 관리용 오늘 수업 목록을 연다. 수업 데이터 확인·수정은 격자 아래 `시간표 원본 · 관리용` 영역에서 진행한다. 접기 영역으로 배치했다면 펼쳐서 확인한다. 파일·컴시간 반영 후 원본 수업과 두 페이지의 격자가 갱신되며 수업은 업무·일정이나 To-Do에 자동 추가되지 않는다. 격자 직접 편집은 원본 DB를 바꾸지 않는다. 공유 표의 수동 변경은 다른 페이지에도 보일 수 있다. 새 업무는 수집함에 한 줄로 적는다. 할 일의 실행 날짜와 제출 마감이 다르면 둘 다 입력한다.

## 수업과 학생 기록

교과 페이지에서 수업 후 해당 반·단원의 완료 차시와 다음 수업을 기록한다. 학급 페이지에서 학생 관찰 태그와 집중 관찰을 관리하고 조회·종례 메모에는 날짜를 함께 적는다. 학생 상담은 관찰 사실과 합의 사항을 구분해 적고 후속 업무를 연결한다. 출결·제출물은 반별로 확인한다. 직접 새 행을 만들 때 학년도를 넣는다.

## 금요일

학사 캘린더 & PARA 페이지에서 다음 주 일정과 마감을 확인한다. 수집함에서 분류·우선순위·다음 행동을 정한다. P2 업무의 다음 주 시간을 확보한다. 끝난 프로젝트와 더 이상 쓰지 않는 자료에 보관을 체크한다. 보관은 삭제가 아니며 관계는 유지된다. 학기/학년도 전환 시 학급과 진도는 새 기록으로 시작한다.

## AI에게 맡기는 예

```text
이번 주 미완료 업무를 보고 우선순위 조정안을 제안해줘.
마감과 중요도를 나눠 설명하고, 내가 선택한 변경을 반영해줘.

1학년 1반 영어 2단원 진도를 보여줘.
오늘 한 차시를 진행했으니 완료 차시를 1 늘리고 다음 수업을 본문 독해로 적어줘.

이 회의록의 결정 사항을 후속 업무로 만들어줘.
담당이나 마감이 명시되지 않은 것은 추정하지 말고 비워 두거나 물어봐줘.

이 상담 기록에 다음 주 화요일 후속 확인 일정을 연결해줘.
캘린더 제목에는 학생 이름이나 상담 내용을 넣지 마.

이 시간표 파일을 검사한 뒤 내 Notion 시간표에 반영해줘.
변경 수업은 교사 시간표에 갱신하고 휴강을 표시해줘.
홈과 교과 페이지의 주간표에서 같은 주와 수업이 보이는지 확인하고, 업무·일정에는 복사하지 마.
```

AI가 학생 기록을 읽는 요청은 필요한 학생과 날짜로 범위를 좁힌다. 기록의 사실관계를 임의로 보완하거나 보호자에게 자동 발송하지 않는다. 일정 등록 자체가 알림이나 반복 실행을 설정하는 것은 아니다.
