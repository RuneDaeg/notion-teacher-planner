# 노션 교무수첩

먼저 교사가 요청한 대상이 새 수첩인지 이미 쓰는 수첩인지 확인한다. 이전 대화, 웹 설문 답, 수첩 링크가 있으면 재사용한다. “가능한지 알려 줘”, “먼저 보여 줘”와 같은 요청에는 설명이나 미리보기까지 제공한다.

## 작업 기준 찾기

아래 경로는 모두 [교무수첩 저장소](https://github.com/RuneDaeg/notion-teacher-planner)의 루트 기준이다. 실제 설치·수정에 앞서 사용할 저장소의 `START_HERE.md`와 `AGENTS.md`를 읽는다. 방법만 설명할 때는 아래에서 해당 절차를 바로 찾는다. 스킬만 설치된 경우에는 공개 저장소의 문서를 열거나 작업 폴더에 저장소를 복제한다. 한 작업 안에서는 문서와 CLI의 저장소 버전을 맞춘다. GitHub에 접근할 수 없으면 교사가 제공한 저장소 ZIP도 사용할 수 있다. Python 명령은 저장소 루트에서 Python 3.10 이상으로 실행한다.

## 요청에 맞게 진행하기

- **새 학년도 수첩.** `docs/ONBOARDING.md`의 공통 질문에서 아직 답하지 않은 문항만 원래 순서대로 2~3개씩 묻는다. 웹 설문에서 선택한 기능·양식과 생성 위치를 재사용한다. 학년도마다 한 권을 만든다. 지정한 부모 페이지에 쓸 수 있으면 `docs/INSTALL_WITH_MCP.md`의 Notion 도구 경로 또는 `START_HERE.md`의 Python 설치 경로 중 하나를 사용한다. Python에서는 먼저 `python -m teacher_planner plan --config .local/config.json`으로 선택 사항을 확인한다. 쓰기 도구가 없으면 설정과 이어서 사용할 설치 요청문을 전달한다.
- **기존 수첩 수정.** `docs/ITERATIVE_EDITING.md`에 따라 대상 페이지와 원본 DB·보기를 먼저 읽고, 요청한 부분을 그 자리에서 수정한다. 예를 들어 “학생 페이지에서 상담 이력을 보여 줘”라면 기존 학생↔상담 관계를 확인하고 해당 학생의 기록만 최근 상담일부터 보이도록 설정한다. 화면 설정은 `docs/INSTALL_WITH_MCP.md`의 ‘학생 페이지에 누적 상담 이력 연결’을 따른다. 기존 상담이 있는 단방향 관계를 전환해야 하면 `docs/UPDATES.md`에 따라 변경 전후에 전체 상담–학생 연결 ID를 대조한다. 서로 다른 두 학생의 화면에서 필터와 정렬을 확인한다. 선택한 관계·상세 보기는 `docs/WORKFLOWS.md`, 배포된 업데이트 항목 적용은 `docs/UPDATES.md`를 따른다. 원래 설치 기록과 ID를 유지한다. 개인 수첩 수정에 새 설치 명령을 실행하지 않는다.
- **미리보기 배치 적용.** 교사가 확인한 `reviewed-layout.json`으로 적용해 달라고 하면 `docs/PREVIEW.md`를 읽고 `python -m teacher_planner verify-preview --bundle .local/reviewed-layout.json`으로 파일을 검증한다. 새 Python 설치의 계획·생성과 최종 배치 검사에 같은 파일을 `--reviewed-bundle`로 전달한다. 기존 수첩이면 요청한 구역만 수정한다. 지정한 파일을 받지 못했거나 설문 선택과 충돌하면 쓰기 전에 그 항목만 확인한다. 기본 배치로 만들어 달라는 요청에는 파일 없이 공통 배치 명세를 사용한다.

## 실제 결과 확인하기

새 설치는 `docs/ACCEPTANCE.md`에 따라 네 페이지의 전체 너비·열 폭·접기 상태와 원본 DB 연결을 실제 Notion에서 확인한다. 홈과 교과 페이지의 주간 시간표는 같은 표를 보여 주고, 주간·월간 캘린더는 같은 업무·일정 원본의 보기여야 한다. 수업은 업무 To-Do에 넣지 않는다. 부분 수정은 바꾼 화면과 연결된 보기만 다시 열어 확인한다.

교사에게 대상 페이지 링크, 실제 확인한 동작과 추가 확인이 필요한 항목을 알려 준다. 웹 미리보기와 CLI 계획 결과는 실제 설치 증거로 쓰지 않는다. 설치 상태와 화면 증거는 비공개로 보관하며, 채팅이나 공개 저장소에 토큰·학생 정보·상담 원문을 요청하거나 싣지 않는다.
