이 저장소의 START_HERE.md와 AGENTS.md를 읽고 내 Notion에 미니 교무수첩을 만들어줘.
이미 알려준 설정은 다시 묻지 말고, 학교급·학년도·담당 반·교과·담임 여부와 추가 모듈 선택을 확인해줘.
추가 모듈 후보는 출결·제출물, 평가·채점, 학부모 연락, 회의록, 교직원 연락망, 학교 계정 관리야.
teacher_planner/layout_contract.json의 teacher-desk-layout-v1 / 버전 1과 docs/DEFAULT_TEMPLATE.md를 읽고 기본 네 페이지의 행·열·폭·접기를 그대로 재현해줘. 네 페이지 모두 전체 너비 켜기·작은 텍스트 끄기를 기본으로 해줘. 홈 빠른 실행 4열, 중식/할 일·마감 40/60, 출결/상담 50/50, 진도/평가 55/45, 전폭 시간표·캘린더, 하단 문서 보관실, 관리용 원본 닫힌 접기를 지켜줘. 선택하지 않은 모듈만 생략하고 남은 열의 폭을 정규화해줘. 모든 DB를 세로로 쌓는 배치로 대체하지 마.
내가 지정한 부모 페이지에 새 수첩을 만들고, 기존 Notion은 임의로 정리하지 마.
사용 가능한 Notion 연결 도구가 없으면 연결에 필요한 것과 가능한 범위를 알려줘.
실제 생성 후 docs/ACCEPTANCE.md를 따라 관계·주간/월간 캘린더·필터와 실제 블록 트리를 다시 조회해줘. 네 페이지 화면·각 전체 너비 메뉴·닫힌 접기·열 배치도 실제 캡처로 확인하고 증거는 .local/에만 저장해줘. 가능한 로컬 경로에서는 layout-plan으로 목표를 확인하고 실제 재조회 스냅샷을 verify-layout으로 대조해줘. 도구에 없는 API 필드를 추정하지 말고 지원하지 않는 부분은 MCP/UI로 마무리해줘. 기능 설치·배치 재현·선택 연동을 따로 보고하며 화면을 확인하지 못하면 설치 완료가 아니라 배치 확인 대기로 알려줘.
