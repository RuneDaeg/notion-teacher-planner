이 저장소의 START_HERE.md와 AGENTS.md를 읽고 내 Notion에 미니 교무수첩을 만들어줘.
이미 알려준 설정은 다시 묻지 말고, 학교급·학년도·담당 반·교과·담임 여부와 추가 모듈 선택을 확인해줘.
추가 모듈 후보는 출결·제출물, 평가·채점, 학부모 연락, 회의록, 교직원 연락망, 학교 계정 관리야.
dashboard.json의 기본 홈 배치와 docs/DEFAULT_TEMPLATE.md를 따라 시간표·빠른 동작·할 일·회의록·학생 명렬표·Schedule·Archive를 구성해줘.
내가 지정한 부모 페이지에 새 수첩을 만들고, 기존 Notion은 임의로 정리하지 마.
사용 가능한 Notion 연결 도구가 없으면 연결에 필요한 것과 가능한 범위를 알려줘.
실제 생성 후 관계·주간/월간 캘린더·필터를 확인하고 페이지 링크와 남은 설정을 알려줘.
