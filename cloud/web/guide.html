이 안내서의 선택 기능은 설치된 경우에 사용할 수 있습니다. 현재 예시 수첩에는 여섯 기록 양식과 학생별 상담 이력 보기를 등록했습니다. 새 수첩을 만들 때는 사용할 기능과 연결 상태를 확인하세요.

1 아침 일과와 할 일 관리

아침에는 홈에서 확인하기

시간표의 표시 주간과 오늘 날짜를 먼저 확인합니다. 오늘 중식의 기준 날짜를 보고, 오늘 상담·출결과 다가오는 일정을 확인한 뒤 P1과 P2 업무부터 살펴보세요. 새로 들어온 일은 수집함에 한 줄로 남기고 나중에 분류해도 됩니다.

업무 한 건 입력하기

  1. 1. 제목과 종류 ‘평가 계획 초안 작성’처럼 해야 할 일이 드러나는 이름을 적고 종류를 선택합니다.
  2. 2. 업무 분류와 우선순위 수업·담임·행정·평가·상담·연수 중 해당 분류를 고릅니다. 아래 기준으로 P1~P4를 정합니다.
  3. 3. 실행할 날짜와 제출 기한 일정은 실제로 처리할 시간, 마감은 반드시 끝내야 할 기한입니다. 서로 다르면 각각 입력합니다.
  4. 4. 다음 행동과 상태 ‘평가 기준표 초안 3항목 작성’처럼 바로 할 행동을 적습니다. 진행·대기·완료 등 실제 상태로 갱신합니다.

주간과 월간은 같은 일정을 봅니다

캘린더 위쪽의 ‘주간’과 ‘월간’ 탭을 바꾸면 같은 업무·일정 기록을 다른 범위로 볼 수 있습니다. 일정을 두 번 입력하지 마세요. 주간·월간은 ‘일정’ 날짜를, ‘마감’ 보기는 ‘마감’ 날짜를 사용합니다.

예를 들어 10월 7일에 검토하고 10월 9일까지 제출한다면 일정은 10월 7일, 마감은 10월 9일로 넣습니다. 일정이 비어 있으면 주간·월간 캘린더에서 보이지 않을 수 있으므로 날짜 미정 보기나 원본 목록에서 찾습니다.

상담·회의·평가 기록을 업무와 연결해도 날짜가 자동 복사되지는 않습니다. 달력에 필요한 일만 업무·일정에 등록하고 원본 기록과 연결하세요. 일정 등록만으로 알림이나 반복 실행이 설정되지는 않습니다.

2 학생을 열고 상담 이력 확인하기

학생 페이지에서 누적 기록 보기

‘학급 경영 & 학생 상담’에서 학생 명렬표 또는 학생 카드 보기를 열고 학생 이름을 누릅니다. 학생 페이지의 ‘상담 기록’에는 그 학생과 연결된 상담 원본이 모이며, 현재 예시 수첩은 상담일 최신순으로 표시합니다. 항목을 누르면 상담 내용을 열 수 있습니다.

이력은 해당 학생 페이지에 연결된 전체 기간의 기록을 봅니다. 제목이나 본문에 학생 이름만 적은 상담은 자동으로 연결되지 않습니다. 다음 해에 같은 이름의 새 학생 페이지를 만들더라도 두 사람의 이력을 임의로 합치지 않습니다.

새 상담을 남기는 순서

  1. 1. 상담 양식 선택 상담 기록 DB의 ‘새로 만들기’ 옆 화살표에서 ‘학생 상담 기록’을 선택합니다.
  2. 2. 학생과 날짜 연결 ‘학생’ 속성에서 실제 학생을 선택하고 상담일·대상·주제·학년도를 입력합니다.
  3. 3. 관찰과 합의 구분 관찰한 사실, 학생이 말한 내용, 합의 사항, 다음 확인할 일을 구분해 적습니다. 상태는 예정·진행·추적·종결 중에서 선택합니다.
  4. 4. 후속 확인 연결 후속 확인일을 적고 필요하면 업무·일정에 확인 업무를 만든 뒤 ‘후속 업무’로 연결합니다.
  5. 5. 학생 페이지에서 확인 학생을 다시 열어 새 상담이 이력에 보이는지 확인합니다. 상담 내용을 복사해 붙일 필요는 없습니다.

연결이 되는 예

상담 기록의 학생 속성에서 ‘학생 A’를 선택하면 학생 A의 상담 기록 목록에도 같은 상담이 나타납니다. 상담 내용을 수정하면 양쪽에서 여는 원본 내용이 함께 바뀝니다. 이름이 같은 학생이 있다면 학급·번호·학생 ID로 구분하세요.

출결과 제출물도 학생에 연결하기

출결은 학생·학급·날짜와 상태를 기록하고 확인 여부를 체크합니다. 제출물은 항목·학생·마감과 미제출·제출·보완 요청·확인 완료 상태를 관리합니다. 이 수첩의 체크 결과를 공식 NEIS에 자동으로 전송하지는 않습니다.

학부모 연락은 별도 기록으로 남기기

학부모 연락 DB에서 연락 양식을 선택하고 학생, 연락 요지, 합의 사항과 후속 업무를 기록합니다. 연락 기록을 작성해도 메시지가 자동 발송되지는 않습니다. 학생의 ‘상담 기록’ 목록은 상담 기록 DB를 보여 주므로 학부모 연락 DB는 별도로 확인합니다.

공유 캘린더에는 ‘상담 후속 확인’처럼 중립적인 제목을 사용하세요. 학생 상담의 상세 내용은 접근이 필요한 사람만 볼 수 있는 학생 기록 영역에 둡니다.

3 주간 시간표와 수업 진도 관리

홈과 교과 페이지에서 같은 주간표 보기

홈의 ‘오늘의 수업 · 주간 시간표’와 교과 페이지의 주간표는 같은 표시 블록을 공유합니다. 왼쪽의 교시·수업시간과 가로의 월~금 날짜를 교차해 담당 반과 교과를 확인하세요. 제목의 표시 주간은 마지막으로 반영한 주를 뜻합니다.

빈칸은 그 주에 조회된 수업이 없는 교시입니다. 표가 보인다는 이유만으로 최신 시간표라고 판단하지 말고 표시 주간과 조회 시점을 확인하세요. 수업은 업무 일정이나 To-Do에 자동으로 추가되지 않습니다.

컴시간 시간표 갱신 요청하기

컴시간 웹 연동을 선택했다면 학교 코드·교사 번호와 담당 반·교과를 확인해 연결합니다. 정확한 수업 시각을 표시하려면 학교의 교시별 시작·종료 시각도 필요합니다. 컴시간 학교 코드와 NEIS 표준학교코드는 서로 다릅니다.

AI 요청 예 “컴시간에서 이번 주 내 시간표를 조회하고 변경·휴강을 확인해 반영해줘. 홈과 교과 페이지가 같은 주를 표시하는지 확인하고, 업무·일정에는 수업을 넣지 마.”

컴시간 웹 자료 형식이 바뀌어 조회가 실패하면 이전 정상 시간표를 기준으로 상황을 확인하고 CSV/JSON 파일 경로를 사용할 수 있습니다. 급식·학사일정의 일일 자동 갱신에는 컴시간이 포함되지 않습니다.

표를 직접 고치기 전에 확인하기

표 아래 ‘시간표 원본 · 관리용’에서 수업 원본과 오늘 수업·변경·휴강 보기를 확인합니다. 표시용 주간표를 직접 수정하면 홈과 교과 페이지에 함께 보이지만 원본 DB로 역전송되지 않습니다. 시간표 변경은 원본과 표시표가 일치하도록 갱신 요청을 하는 편이 좋습니다.

수업 후에는 완료 차시와 다음 수업 기록하기

  1. 1. 반과 단원 찾기 수업 진도에서 교과·학급·학기 보기를 골라 해당 단원을 엽니다. 이미 있는 같은 반·단원 기록을 우선 수정합니다.
  2. 2. 완료 차시 수정 계획 차시와 완료 차시를 확인하고 실제로 진행한 만큼 반영합니다. 진도율은 입력된 차시를 기준으로 계산됩니다.
  3. 3. 다음 수업 기록 다음에 할 내용과 보충할 부분을 남깁니다. 본문의 체크박스만 눌러도 완료 차시가 자동 증가하는 것은 아닙니다.

평가와 채점 현황 기록하기

평가일·채점 마감·대상 인원·채점 완료 인원과 상태를 입력합니다. 채점률은 해당 숫자를 기준으로 계산됩니다. 전체 캘린더에도 보여야 하는 평가 일정은 업무·일정에 등록하고 연결하세요.

‘새로 만들기’에서 양식을 선택해 만든 페이지는 이번 기록입니다. 템플릿 편집 화면은 이후 새 기록에 반복 사용할 원본입니다. 특정 학생 이름이나 이번 상담 날짜는 새 기록에 쓰고, 템플릿 원본은 빈 작성 항목으로 유지하세요.

템플릿의 학년도는 수첩에 맞게 설정되어 있어도 새 학년도에 다시 확인해야 합니다. 이 수첩에서는 양식 등록만으로 매일 기록을 반복 생성하도록 설정하지 않았습니다.

양식 모음을 사용하는 방법

홈의 ‘양식 모음’에서는 같은 작성 항목을 미리 볼 수 있습니다. 필요한 양식을 복제해 안내된 DB로 옮기거나, 해당 DB의 새 페이지 본문에 작성 양식만 복사해 사용합니다. 본문을 복사한 뒤에도 날짜·학생·학급 등 DB 속성은 따로 입력합니다.

양식 모음의 페이지와 DB 템플릿은 별도로 관리합니다. 한쪽을 수정해도 다른 쪽의 내용이 자동으로 바뀌지 않으므로 둘 다 바꾸려면 함께 수정을 요청하세요. 새로 설치한 수첩에 복사용 양식만 있다면 DB 템플릿 등록도 요청할 수 있습니다.

같은 내용을 중복 입력하지 않기

  • 수업 진도는 같은 반·단원 행이 있으면 그 기록을 수정합니다. 매 수업마다 같은 진도 행을 새로 만들면 집계가 중복될 수 있습니다.
  • 회의의 결정 사항 중 실행이 필요한 것만 업무·일정으로 만들고 회의록과 연결합니다.
  • 본문의 표·체크박스와 DB 속성은 별개입니다. 완료 차시, 평가일, 채점 완료 인원 등 계산에 필요한 값은 속성에 입력합니다.

5 오늘 중식과 학사일정 갱신

홈에서는 중식만 확인하기

‘오늘의 중식’에는 NEIS에서 조회한 중식 메뉴와 제공된 열량을 표시합니다. 학교·기준 날짜·마지막 확인 시각·출처와 메뉴의 알레르기 번호도 함께 확인하세요. 조식·석식은 홈에서 생략합니다.

‘해당 날짜에 공개된 중식 정보가 없습니다’는 공개 자료에 중식 항목이 없다는 뜻입니다. 급식을 제공하지 않는다는 확정 정보와는 다릅니다. 조회 오류가 생기면 마지막 정상 표시가 남을 수 있으므로 날짜를 확인하세요. 개인 메모는 자동 갱신 영역 밖에 적습니다.

연속되는 학사일정은 기간으로 보기

같은 학교·학년도·학교과정·주야과정에서 이름이 정확히 같은 행사가 하루씩 연속되면, 시작일과 종료일이 있는 하나의 행사 페이지로 묶습니다. 중간 날짜가 빠지면 주말이라도 건너 합치지 않습니다. 날짜별 대상 학년과 설명 차이는 원문에 보존합니다.

학사 캘린더의 주간·월간 탭에서 같은 행사 원본을 봅니다. 새로고침할 때 기존 기간 페이지를 재사용하며 수동 메모·관계를 보존합니다. 모호한 기간 축소나 분리, 중복은 자동으로 정리되지 않을 수 있으므로 확인을 요청하세요.

하루 한 번 자동 갱신을 쓰려면

  1. 1. 연결 링크 열기 운영 중인 클라우드 서비스가 제공하는 개인 연결 링크를 엽니다. AI가 기존 설치 정보로 준비한 학교·학년도·수첩 대상을 확인합니다.
  2. 2. Notion에서 승인하기 이미 만든 교무수첩을 선택해 서비스 연결을 승인합니다. 교사가 클라우드 콘솔에 학교 정보를 다시 입력하거나 운영자 NEIS 키를 복사할 필요는 없습니다.
  3. 3. 첫 성공 확인하기 연결 상태뿐 아니라 실제 반영 날짜와 마지막 성공 시각을 확인합니다. 처음에는 중식이 먼저 표시되고 전체 학사일정 처리가 오래 걸릴 수 있습니다. 처리 중에는 마지막 성공 시각이 아직 바뀌지 않을 수 있습니다.

기본 목표는 한국 시간 오전 7시 이후 하루 한 번 갱신을 완료하는 것입니다. 대기열과 실행 한도에 따라 실제 반영 시각은 달라집니다. 연결이 활성화된 서버 예약은 개인 컴퓨터가 꺼져 있어도 실행됩니다.

6 PARA와 주간 정리

업무를 어디에 둘지 정하기

PARA는 할 일의 우선순위와 별개로 업무와 자료를 정리하는 기준입니다. P1~P4는 먼저 할 일을 고르는 값이고, PARA는 그 일이 어떤 목표·책임·자료에 속하는지 정합니다.

  2. 2. 다음 주 날짜 확인 주간 캘린더와 마감 보기를 함께 열어 실행할 날과 제출 기한이 맞는지 확인합니다. P2 준비 시간을 먼저 확보하세요.
  3. 3. 기다리는 일 확인 대기 상태의 회신·서류·확인 업무를 살펴보고 다음 확인일을 정합니다.
  4. 4. 후속 기록 점검 상담·학부모 연락·회의에서 약속한 일이 업무·일정에 연결되어 있는지 확인합니다.
  5. 5. 완료와 보관 구분 끝난 일은 완료로, 현재 보기에서 정리할 기록은 보관으로 처리합니다. 보관은 삭제가 아니며 기존 관계는 유지됩니다.

학기와 학년도가 바뀔 때

2학기에도 같은 수첩을 이어 쓰며 학생·상담·업무 기록을 보존합니다. 진도의 학기는 필요한 기록에서 선택해 1·2학기 보기로 구분합니다. 제목에 ‘1학기’가 있으면 원할 때 제목만 바꿉니다.

새 학년도에는 이전 수첩을 보존하고 새 수첩을 준비합니다. 양식 기본값·캘린더 필터·학교 연동 학년도를 확인합니다. 과거 학년도를 일괄 바꾸거나 학생 이름만으로 기록을 합치지 않습니다. 클라우드 연동은 학년도를 자동 전환하지 않습니다.

학교 업무 바로가기 관리

교직원 연락망에는 부서·직책·교내 연락처·담당 업무를 정리합니다. 학교 계정 관리에는 서비스 주소, 계정 ID, 관리 담당과 비밀번호 관리 도구의 위치 링크를 남깁니다. 비밀번호·복구 코드·API 키는 수첩이나 공개 저장소에 적지 않습니다.

NEIS·K-에듀파인 링크는 해당 서비스를 여는 바로가기입니다. 연결된 서비스에 출결이나 결재가 자동 입력되는 기능으로 사용하지 마세요.

7 자주 막히는 부분 해결하기

새로 쓴 기록이 보이지 않을 때

현재 보기의 학년도·보관·상태·날짜 필터를 확인합니다. 새 기록의 학년도나 날짜가 비어 있으면 원본에는 있어도 현재 보기에서 숨겨질 수 있습니다. 먼저 원본 목록이나 날짜 미정 보기를 확인하고 중복 페이지를 만들지 마세요.

학생의 지난 상담이 빠졌을 때

상담 원본의 ‘학생’ 속성에 정확한 학생 페이지가 연결되어 있는지 확인합니다. 제목의 이름만으로는 연결되지 않습니다. 같은 이름의 다른 학생 페이지를 선택하지 않았는지도 확인하세요. 관계만 설치된 새 수첩은 학생의 ‘상담 기록’ 속성에서 열 수 있으며, 목록 배치를 원하면 공통 레이아웃 적용을 요청합니다.

시간표나 급식이 지난 날짜일 때

시간표의 표시 주간, 급식 기준 날짜, 마지막 성공 시각을 확인합니다. 컴시간 갱신과 급식·학사일정 갱신은 서로 다른 경로입니다. 자동 연결 상태가 준비 중·일시 중지·오류인지 확인하고 해당 연동의 갱신을 요청하세요.

체크박스를 눌렀는데 숫자가 바뀌지 않을 때

본문에 있는 체크박스와 계산에 쓰는 DB 속성은 별개입니다. 수업은 완료 차시, 평가는 채점 완료 인원을 수정합니다. 업무 완료는 해당 업무의 상태를 완료로 바꾸세요.

AI에게 바로 요청할 문장

  • “이 학생 페이지에 연결된 지난 상담을 날짜순으로 보여줘. 이름만 같은 다른 학생은 합치지 마.”
  • “이 회의록의 결정 사항을 후속 업무로 만들어줘. 담당과 기한이 없는 항목은 추정하지 말고 물어봐줘.”
  • “이 상담에 다음 주 화요일 후속 확인 일정을 연결해줘. 캘린더 제목에는 학생 이름과 상담 내용을 넣지 마.”
  • “현재 상담 양식에 후속 확인 체크 항목을 추가해줘. 기존에 작성한 상담은 유지하고, 양식 모음과 DB 템플릿을 함께 수정해줘.”

다른 교사가 새 수첩을 만들 때

웹 질문지의 5단계 답변을 마친 뒤 생성된 요청문을 복사해 AI에 전달합니다. AI가 Notion 쓰기 권한과 생성 위치를 확인하고 선택한 기능으로 수첩을 만듭니다. 직접 시작하려면 저장소 링크와 “START_HERE.md 순서대로 내 Notion에 교무수첩을 만들어줘”라는 요청을 전달해도 됩니다. Notion 쓰기 연결이나 실행 도구가 없으면 설정 준비까지만 가능합니다.

웹 질문지 · 공개 저장소 · 상세 사용법과 기록 양식

기능 기준 2026년 10월 2일, 업데이트 목록 2026.10.1. 선택 기능의 설치 여부와 Notion 언어·보기 설정에 따라 화면 위치와 메뉴 이름은 다를 수 있습니다.

8 기존 수첩에 새 기능 적용하기

새 기능은 홈의 ‘업데이트 확인’에서 선택해 적용합니다. 이미 만든 수첩의 학생 기록과 직접 꾸민 페이지는 유지합니다.

처음 사용하는 기존 수첩이라면

AI가 기존 설치 기록에서 데이터베이스 위치를 확인하고 홈에 업데이트 링크를 추가합니다. 학교 정보나 API 키를 다시 적지 않습니다. 클라우드 미연결 수첩은 AI와 직접 적용하고 설치 기록에 이력을 남깁니다.

“기존 교무수첩에 docs/UPDATES.md의 업데이트 경로를 연결해 줘. 기록과 화면을 보존하고, 학생별 상담 이력 연결부터 적용 상태를 확인해 줘.”

업데이트 적용 순서

  1. 1. 업데이트 확인 열기 홈의 링크를 엽니다. 연결이 만료되었다면 Notion에서 같은 수첩을 다시 허용합니다.
  2. 2. 변경 내용 읽고 선택하기 ‘학생별 상담 이력 연결 · 2026.10.1’을 확인하고 ‘이 업데이트 적용’을 누릅니다. 적용 중에는 관련 DB 편집을 잠시 멈춥니다.
  3. 3. 남은 화면 설정 확인하기 학생 창에 해당 학생의 지난 상담이 모이고 상담일 내림차순인지 확인합니다. 목록이 없거나 다르면 AI에게 공통 레이아웃 설정을 요청합니다.
  4. 4. 확인 완료 남기기 목록과 정렬을 확인한 뒤 체크하고 ‘화면 확인 완료 기록’을 누릅니다. 이 화면 확인은 사용자가 확인했다는 기록입니다.
