Notion에서 이미 만든 교무수첩을 선택하고 접근을 허용하면 연결됩니다. API 키나 학교 정보를 다시 입력할 필요가 없습니다.

연결 과정에는 학교·학년도, 갱신할 페이지 위치와 Notion 접근 권한이 사용됩니다. 학생 명단과 상담 내용은 등록 정보에 포함하지 않습니다.

갱신에 실패하면 기존 내용을 유지하고 다시 시도합니다. 학교가 아직 공개하지 않은 급식은 공개 정보가 없다고 표시합니다.
