처음 한 번만 허용해 주세요.

Notion에서 이미 만든 교무수첩을 선택하고 접근을 허용하면 연결됩니다. API 키나 학교 정보를 다시 입력할 필요가 없습니다.

자동 갱신 연결에는 학교·학년도, 갱신할 페이지 위치와 Notion 접근 권한이 사용됩니다. 수첩 업데이트를 선택하면 학생·상담 데이터베이스와 관계 속성의 식별자, 적용 단계도 저장합니다. 학생 이름이나 상담 본문을 업데이트 이력에 저장하지 않습니다.

갱신에 실패하면 기존 내용을 유지하고 다시 시도합니다. 학교가 아직 공개하지 않은 급식은 공개 정보가 없다고 표시합니다.
